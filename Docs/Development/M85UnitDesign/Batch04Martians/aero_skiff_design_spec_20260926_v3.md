# Aero Skiff — Production Design Target

**Стан T083:** директор затвердив Production Design Target 2026-09-26; T084 не авторизовано й не розпочато.
**Юніт:** `unit.martians.aero_skiff` · **фракція:** Martians · **роль:** легкий повітряний транспорт.
**Режим:** `SOURCE_LOCKED`.

## Production Design Target

Зберегти завершений Martian craft LEGO 1195 *Alien Encounter* без видимих ігрових адаптацій. Його композиція симетрична відносно центральної поздовжньої осі. У напрямку від тилу до носа: круглий світло-сірий радіальний щиток з отворами; по центру щитка — зелена коробка з одним прозоро-зеленим ліхтарем/кристалом зверху; від коробки вперед центральною віссю проходить чорна циліндрична трубка; трубка з’єднується з відкритою трикутною зелено-бірюзовою платформою пілота; на платформі стоять два однакові зелені конусні ліхтарі, симетрично ліворуч і праворуч; оператор розміщений на передньому кінці платформи, за консоллю керування. Зберегти компактний розмір, джерельні кольори та видиму LEGO-конструкцію.

У директорському рев’ю головним зображенням є покращена за якістю AI-візуалізація Production Target, побудована з фото завершеного набору, наданого директором, і його уточнення щодо симетричної композиції. Повне незмінене фото з обома окремими апаратами збережене як Source Evidence. Згенероване зображення не є фотографією, офіційним зображенням LEGO чи part-verified збіркою; воно візуально фіксує погоджений напрям зовнішності й розташування вузлів для рішення директора.

## Що відомо, виведено та лишається відкритим

- **Безпосередньо видно у фото директора:** завершений 1195 Martian craft; один бірюзовий оператор в помаранчевій відкритій рамі; низьку відкриту основу; радіальний щиток; зелений маяк на коробці; чорний центральний вузол; дві окремі зелені конусні деталі; передню консоль. На фото ці деталі перекриті перспективою, через що попереднє читання помилково назвало композицію зміщеною.
- **Уточнення директора для цього Production Target:** вузли розташовані симетрично по центральній осі в послідовності «щиток і коробка → чорна трубка → трикутна платформа з парою ліхтарів → оператор спереду». Це уточнення замінює попередній опис про зміщення/асиметрію; таких тверджень у v3 немає.
- **Перехресні джерела:** скан буклета 1195 показує зібрану композицію й інструкційні кроки Martian craft; інвентар BrickLink підтверджує один чорний трилопатевий пропелер. Brickset та BrickEconomy ідентифікують два апарати набору як людський rover і Martian flyer з пропелером. Огляд Brian’s Bricks дає додатковий верхньо-бічний ракурс, але не повний оберт.
- **Не встановлено:** походження/автор початкового фото; точні LEGO part IDs і приховані точки з’єднання; повний вигляд зі спини, зверху, з протилежного боку та знизу; рухомість операторського вузла. Генерація не усуває ці джерельні прогалини й не є доказом точного конструкційного шляху.

## Видимі адаптації

Видимих адаптацій немає. Друге місце не додається: джерельний зовнішній вигляд має одного оператора. Ігрова місткість сама по собі не визначає кількість фізичних місць у візуальному target.

## Рішення, яке потрібне від директора

Затвердити чи відхилити саме симетричну композицію Production Design Target: задній круглий радіальний щиток із центрованою зеленою коробкою/ліхтарем, центральну чорну трубку, трикутну платформу з двома симетричними конусними ліхтарями та оператора спереду. Рішення стосується тільки зовнішнього вигляду T083. T084 не розпочато й не авторизовано.
