# MX-71 Recon Dropship — T083 Design Spec

**Stable ID:** `unit.astronauts.mx71_recon_dropship`<br>
**Фракція / роль:** Astronauts / повітряний транспорт<br>
**Target mode:** `ADAPTED`<br>
**Стан:** директор прийняв ціль 2026-09-25. T084 авторизовано лише для MX-71; **T084 — НЕ РОЗПОЧАТО.**

## Production Design Target

Зібраний LEGO 7692 є базовим візуальним target: білий високий корпус із довгим вузьким крилом і задніми двигунами, бурштинова прозора кабіна, помаранчеві баки та гнучкі помаранчеві трубки, темні відкриті опори й сині наконечники. Target-зображення — обрізане фото реальної зібраної моделі з незалежного огляду JANG; геометрію, масштаб, кольори та деталі не перемальовано.

`ADAPTED` стосується ігрового вантажу: зберігається носій LEGO 7692 і його відкрите нижнє місце кріплення; замість наборного rover ігровий носій може показувати один дозволений вантаж: Crew, Rover, T3-Trike або Claw-Tank. Вантаж лишається окремим від корпуса; не збільшуйте його заради ефектності, не додавайте закритого відсіку чи додаткової кабіни. Офіційна сторінка інструкції 70 показує саме з'єднання літака з rover. Вона пояснює адаптацію, а не підміняє фото моделі як головний target.

Фото реальної моделі уточнює кольорові та пропорційні помилки попередньої пропозиції: кабіна бурштинова, а не синя; посадкові опори компактні й темні, не високі; чотири сині елементи належать коротким гарматам/наконечникам на корпусі, а не світним панелям.

## Що потрібно затвердити

- Впізнаваний силует і пропорції зібраного LEGO 7692 як основа літака.
- Біло-помаранчеву палітру, бурштинову кабіну, підняте вузьке крило, двигуни й характерні гнучкі трубки.
- Одне відкрите нижнє кріплення та масштаб вантажу, показані набором; у грі воно приймає один із чотирьох зазначених типів вантажу.
- Короткі сині елементи як деталі корпуса, окремо від вантажу.

Директор прийняв цей Production Design Target 2026-09-25. T084 авторизовано лише для MX-71, але роботу не розпочато.
