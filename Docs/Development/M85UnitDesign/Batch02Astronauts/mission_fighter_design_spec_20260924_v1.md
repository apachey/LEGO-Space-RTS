# Mission Fighter — T083 design spec

**Stable ID:** `unit.astronauts.mission_fighter`

**Фракція / роль:** Astronauts / повітряна перевага

**Production Design Target:** `SOURCE_LOCKED`
**Стан:** ГОТОВО ДО РЕВ'Ю; дизайн не затверджено, T084 не розпочато.

## Ціль для виробництва

Ціль Mission Fighter — лише завершений офіційний LEGO 7695 MX-11 Astro Fighter.
Це тонкий, майже однопластинний білий дельтаподібний апарат із виразним
помаранчевим носом-кабіною, малим темним заднім вузлом та антеною. Саме цей
завершений вигляд показано в директорському рев'ю й офіційних інструкціях.

LEGO 5619 Crystal Hawk — інша окрема модель, не варіант Mission Fighter; її не
використовувати для цієї цілі й не змішувати з MX-11.

## Видимі адаптації

Видимих адаптацій немає. Технічні контракти для спільного рига, сокетів,
підсвічування чи анімацій не змінюють форму цих цілей.

## Межа доказів

Інструкції показують переважно верхній/три-чвертний ракурс і складання; чисті
ортогональні види днища та рушіїв відсутні. Їхню приховану конструкцію не
вигадувати на підставі цих зображень. T082 згадує Crystal Hawk поруч із
Mission Fighter як джерельний мотив; ця ціль дотримується уточнення директора,
що це різні моделі, і містить тільки MX-11.
