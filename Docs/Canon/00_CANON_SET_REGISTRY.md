# LEGO SPACE RTS — CANON SET REGISTRY

**Phase:** 00 — Canon Set Registry
**Status:** APPROVED PROJECT CANON
**Approval note:** Canon Set Registry v0.1 was explicitly approved for use as the project source-material baseline.

---

I treated this as a **source-control exercise**, not a gameplay-design exercise. No unit roles, costs, balance, tech trees, economy, campaign structure, or invented variants are assigned below.

For the registry spine, I cross-checked current BrickLink and Brickset catalog records and, where available, LEGO’s current building-instructions archive. BrickLink currently catalogs 18 Rock Raiders release entries; Life on Mars has 26 set-category entries plus the official 3750 service/accessory pack; Mars Mission has 19 released catalog entries. I treat bundles/reissues as official release entries but **not as new physical designs** when they merely repackage existing sets. ([bricklink.com](https://www.bricklink.com/catalogList.asp?catID=62&utm_source=chatgpt.com))

## Canon Registry v0.1 — scope rules

**Included:** normal construction sets, small/impulse sets, promotional polybags, character packs, official service/accessory construction packs, and catalogued collection/bundle releases.

**Separately flagged:** releases whose value to the playable roster is debatable because they are duplicates, bundles, character-only products, service packs, or promotional mini-builds.

**Excluded:** key chains, pens, pins, posters and other non-construction merchandise; cross-theme assortment boxes merely containing one of these sets; MOCs/fan models; later homages; unreleased designs; and generic LEGO Space material.

The abbreviations in the final column are: **Ch** characters, **V** vehicles/craft, **S** structures/installations, **Eq** equipment/tools, **Cr** creatures, **Env** environmental/resource elements.

# 2. Registry counts

There are two useful ways to count this without misleading ourselves.

### A. Official released registry entries

A mixed release counts once in the 64-set total, but it can “touch” two RTS factions.

| Source range | Released registry entries |
|---|---:|
| Rock Raiders | **18** |
| Life on Mars | **27** |
| Mars Mission | **19** |
| **Total** | **64** |

By **exclusive classification** of each release:

| Registry classification | Sets |
|---|---:|
| Rock Raiders only | **18** |
| Astronauts only | **8** |
| Martians only | **16** |
| Aliens only | **1** |
| Astronauts + Martians | **5** |
| Astronauts + Aliens | **16** |
| **Total** | **64** |

By **faction touch**—so a mixed box counts for both sides it physically supplies:

| Future RTS faction | Released set entries containing relevant material |
|---|---:|
| Rock Raiders | **18** |
| Astronauts | **29** |
| Martians | **21** |
| Aliens | **17** |

These counts deliberately do **not** imply 29 different Astronaut vehicles, etc. Bundles and exact reissues create duplicate source material.

### B. Conservative usable source-asset groups

For a better measure of genuinely distinct source material, I collapsed exact reissues and bundles. A “source-asset group” here means one distinct set/design source from which later gameplay assets may be derived; one large source group can eventually yield multiple RTS assets.

| Future RTS faction | Distinct source-asset groups after duplicate/bundle collapse |
|---|---:|
| Rock Raiders | **15** |
| Astronauts | **22** |
| Martians | **14** |
| Aliens | **15** |

This is the count I recommend preserving in canon for now. I would **not** yet convert it into “X units, Y buildings and Z abilities,” because that would start making gameplay-design decisions the current task explicitly excludes.

For Life on Mars specifically, the duplicate families that collapse are:

- Rover: **1413 / 7301 / 7309**
- Double Hover: **1414 / 7300 / 7308**
- Worker Robot: **1416 / 7302**
- Jet Scooter: **1415 / 7303**

The Life on Mars collection SKUs and the Mars Mission/Rock Raiders collection SKUs add no new underlying model designs.

# 3. Sets containing material for more than one RTS faction

These are the important cross-faction source boxes.

### Life on Mars — Astronaut + Martian

**1195 Alien Encounter** is the clearest genuine mixed individual set: separate human and Martian figures and vehicles. ([brickipedia.fandom.com](https://brickipedia.fandom.com/wiki/1195_%22Alien_Encounter%22_Kit?utm_source=chatgpt.com))

**3750 Life on Mars Accessories** is mixed only at the equipment/accessory level.

**78777 Alien Discovery**, **K7317 Life on Mars Kit**, and **kabmars Life on Mars 4-Pack** are mixed because they bundle pre-existing sets from both sides. ([bricklink.com](https://www.bricklink.com/catalogItemInv.asp?S=78777-1&utm_source=chatgpt.com))

### Mars Mission — Astronaut + Alien

The following **individual** releases contain both sides:

**7644, 7645, 7646, 7647, 7648, 7649, 7690, 7691, 7692, 7693, 7694, 7695, 7697, 7699.**

The two collection SKUs **K7690** and **K7699** are also mixed by composition.

An important later-design distinction is already visible from the source material: “mixed” does not always mean both factions received a vehicle. For example, 7694 and 7695 give the Alien side a figure/encounter element but no substantial independent Alien vehicle, whereas sets such as 7691 or 7692 contain meaningful constructed assets for both sides.

That distinction is recorded here factually; no gameplay consequence is being assigned yet.

# 4. Ambiguous / project-decision cases

These should **not** be silently resolved.

| Case | Verified fact | Project decision later |
|---|---|---|
| RR 1274–1277 date | Brickset says 1999; BrickLink says 2000. ([brickset.com](https://brickset.com/sets/year-1999/theme-Rock-Raiders?utm_source=chatgpt.com)) | Pick a canonical metadata convention if a single year is required. |
| RR 1275 name | Brickset uses **Chainsaw Bulldozer**; BrickLink uses **Chain Dozer**. ([brickset.com](https://brickset.com/inventories/theme-Rock-Raiders?utm_source=chatgpt.com)) | Keep both aliases or select display name. |
| LoM 7317 spelling | “Aero Tube Hangar” is the normal/LEGO spelling; some catalog material contains “Hanger.” | Canon should use **Hangar**. |
| 3347–3349 | Genuine character/display products, not conventional gameplay-model sets. | Whether each needs its own later gameplay role or counts through its characters. |
| 3750 | Official service/accessory construction pack, but not a normal retail scene/model. | Whether loose accessory concepts need independent gameplay representation. |
| Exact reissues | Several LoM SKUs are physically the same principal model. | Whether “coverage” means one shared gameplay role can satisfy all duplicate SKUs. |
| Collection SKUs | K4990, kabrock, rrminifigures, 78777, K7317, kabmars, K7690, K7699 package existing material. | Whether bundle coverage is automatically satisfied once all children are covered. I recommend yes, but that is not yet canon. |
| Rock Monsters | Physical creatures occur in Rock Raiders sets such as 4950/4990. | They are source creatures/environment, not automatically a fifth playable faction. |
| Mars Mission aliens included only as figures | Some “mixed” sets give Aliens no substantial separate vehicle. | Whether the figure/encounter itself needs an independent gameplay manifestation. |
| 4127147 Super Value Pack | Official multi-theme assortment containing 4930 Rock Raiders Crew, but it is not itself a Rock Raiders-range set. | Keep excluded unless project canon explicitly tracks cross-theme retail assortments. |
| Non-construction merchandise | Official theme-branded key chains, pens, etc. exist. | Currently excluded from the **set** registry. |

# 7. Completeness assessment

**For released LEGO construction-set/source releases in the defined three theme ranges, I believe this registry is complete enough to serve as the project’s proposed canon baseline: 64 released registry entries.**

The remaining uncertainty is mostly **metadata and scope**, not evidence of missing normal retail sets:

1. The **1999 vs 2000** catalog disagreement for Rock Raiders 1274–1277 remains unresolved at source level. ([brickset.com](https://brickset.com/sets/year-1999/theme-Rock-Raiders?utm_source=chatgpt.com))
2. Certain collection identifiers such as `kabrock`, `rrminifigures`, `kabmars`, `K4990`, `K7317`, `K7690` and `K7699` are unusual catalog/bundle releases rather than unique LEGO model designs.
3. Life on Mars has repeated SKUs for identical/same principal builds; those are preserved because the requested registry is release-complete, but they must not be mistaken for independent designs.
4. Service pack **3750** is included because it is a genuine construction/accessory release associated with Life on Mars, despite being outside the ordinary theme-set category.
5. **7728 Jet Pack** and **7729 Alien Flyer** are official documented designs but explicitly unreleased, so they remain outside released canon unless approved separately. ([brickset.com](https://brickset.com/sets?query=Mars+Mission&utm_source=chatgpt.com))
6. Non-construction branded merchandise and cross-theme assortment packaging remain deliberately excluded.

Most importantly, **nothing in this registry has yet been assigned a gameplay role**. The distinction between “official release,” “distinct physical source design,” and “future RTS asset” remains intact.
